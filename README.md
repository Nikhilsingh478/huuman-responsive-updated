# Huuman ✨

**Huuman** is a sleek, animated testimonial carousel built for showcasing user stories, client feedback, or team member highlights in a stylish and interactive way. It combines modern CSS design, elegant typography, and GSAP-powered infinite scrolling to deliver an engaging visual experience.


## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **GSAP (GreenSock Animation Platform)** for animation
- **JavaScript** (vanilla)
- **shery.js**
